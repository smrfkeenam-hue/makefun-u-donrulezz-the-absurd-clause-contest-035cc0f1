# AGENT.md — The Absurd Clause Contest

Entry: one original English sentence (165 characters), written as an absurd
clause buried deep in a terms-of-service agreement. It reads as genuine
legal boilerplate ("perpetual, irrevocable licence") until the absurd turn:
the licence covers all crumbs the user produces, resellable to pigeons at
market rate.

Run: `python3 main.py` — writes the entry to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), no trailing newline.
Stdlib only (`import os`).
